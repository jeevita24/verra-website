# VERRA — Women's Clothing Website

A responsive, single-page business website for VERRA, a women's clothing brand in Goa, India.

## Files
- `index.html` — website structure
- `style.css` — design and responsive styling
- `script.js` — mobile menu and small interactions

## Run locally
Open `index.html` in a browser.

## Publish for free with GitHub Pages
1. Create a free account at GitHub.
2. Create a new public repository named `verra-website`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open the repository's **Settings → Pages**.
5. Under the publishing/source option, choose the `main` branch and root folder.
6. Save. GitHub will provide a free address such as:
   `https://YOUR-USERNAME.github.io/verra-website/`

## Customize later
Replace the placeholder contact section with your WhatsApp number, Instagram, email, address, and real product photos.
